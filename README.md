# 🏓 桌球比賽獎品採購金額分配系統

輸入賽事的獎品總預算、參賽人數與各名次設定，自動分配預算、計算實際採購支出，並匯出 Excel 採購清單，現場可用來核對。

**網站**：<https://evanchi1111-sys.github.io/tabletennis-prize/>

## 功能

- **賽事總覽**：獎品總預算、參賽總人數。
- **賽別名次獎品設定**：第一～三名與參加獎各自設定「每份預算單價」與份數（兩者相乘＝該名次預算）。參加獎不發放現金，一律以實物發放，依參賽人數計算。
- **獎金分配比例**：選擇比例後，自動算出前三名的每份預算單價（已先扣掉參加獎）。
- **預算上限保護**：參加獎與第一～三名的預算合計不能超過總預算，超過時自動限制輸入。
- **獎品項目清單（六項）**：獎盃、獎牌、禮券等實際採購項目；「對應獎項」可複選（例如同一項同時作為第二名與第三名獎品）。**只有這份清單的金額才計入實際支出**。
- **名次預算比對**：各名次的預算、已採購金額與差額，看是否超支或還有餘額。
- **預算分配建議**：扣除已確定的支出後，估算剩餘可用預算，供調整單價時參考。
- **支出彙總與採購報表**：顯示總支出與是否超出預算。
- **匯出 Excel**：下載採購清單。
- 資料自動存在瀏覽器（localStorage），重新整理不會消失；支援手機與深色模式。

## 使用流程

1. 填「獎品總預算」與「參賽總人數」。
2. 設定第一～三名、參加獎的預算（可用分配比例自動算）。
3. 在「獎品項目清單」填入實際要買的東西、金額，並勾選對應獎項。
4. 看「名次預算比對」與「支出彙總」，調整到不超支。
5. 按「匯出 Excel 採購清單」。

## 注意

- 資料只存在**該台裝置的瀏覽器**，換手機或清除瀏覽資料就會不見，重要資料請先匯出 Excel。
- 名次的「預算金額」只是採購參考，**不會單獨計入總支出**；實際支出以獎品項目清單為準。
